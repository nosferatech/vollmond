## Question

An escape that does not decode to UTF-8, as in `#%E9`, matches the grammar's `pct-encoded`, so by Appendix D's wording it is not
`address-malformed`, though no step or token can hold it. The code says `address-malformed` (#83, its sixth open question, and
deviation 7 on #15). What is it?

## Options

- **(a) `address-malformed`**, and §7.1 and Appendix D say that an escape must decode to UTF-8. Chosen, as recommended.
- **(b) Keep the draft's wording**, under which the address matches the grammar and so is not `address-malformed`.

## Decision

(a), as part of card R's option (a), accepting every recommendation.

## Why

The card's reason: such an escape cannot name any key. Card R as a whole "matches what the code already does and keeps results the
same across implementations".

Why the other options lost: Not recorded.
