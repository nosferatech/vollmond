## Question

§6.2 writes tags as HTML's `class`, but did not say how the attribute becomes `$tags`. For `# Record` with
`<a id="top" class="open incident open"></a>`, what are the order and the repeats? (#54, question 16.)

## Options

- **(a) The tokens in source order, a repeated token dropped with a warning.** Chosen, as recommended: `["open", "incident"]`.
- **(b) The tokens in source order, a repeat kept:** `["open", "incident", "open"]`.
- **(c) A repeat is a validation issue.**
- **(d) Sorted order.**

## Decision

(a), as card H3's option (a), accepting every recommendation. `$tags` from `<a class>` are the class tokens in source order. A
repeated token is dropped, with a warning under a new code, `duplicate-tag` (§6.2).

## Why

The PR's reason: a tag labels a node at most once. Why the other options lost: Not recorded. The card's note for all sixteen
items: each recommendation keeps vmd strict and its output readable back, and none contradicts an earlier decision.

## Applied in

Draft v0.5 (#57, `d0d1424`), §6.2; the code `duplicate-tag` was named by the author. I1.5 later kept a repeated tag in a data
`$tags` array as written, with the same warning, while `class` tokens are still dropped.
