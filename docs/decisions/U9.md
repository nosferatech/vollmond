## Question

§9.3's example of `x-vmd-ref` mixes `tickets`, a collection, and `docs/**`, a glob, in `targets`. How is an entry read?

## Options

- **(a) A collection name if one exists, else a glob.** Chosen, as recommended. An entry naming a collection of the configuration
  is that collection, and any other entry is a glob. With [U10](U10.md)'s names, a collection never looks like a glob.
- **(b) An explicit prefix (`collection:tickets`).** Explicit, but changes Appendix A's schema.

## Decision

(a). §9.3 states it.

## Why

The card's reason: "Simple, and unambiguous given U10." The design: with U10's names, a collection is never confused with a glob
holding `/` or `*`. (b) changes Appendix A's schema.
