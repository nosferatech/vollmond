## Question

§8.1 names inline links and link reference definitions as references, not images. vampiredb's docs have none; tickets with
screenshots will. Are images references?

## Options

- **(a) Images are references.** Chosen, as recommended. A missing image is `ref-dangling`. §8.1's table gains a row.
- **(b) Images are not references.** As stated.

## Decision

(a): an image is a reference, so a missing image is `ref-dangling`.

## Why

The card's reason, which is also the case against (b): "A broken image is the broken link a reader sees first."
