## Question

For a Markdown file that starts with a UTF-8 byte order mark and then `---`, is front matter still "at the very start of the
file", and is the BOM content? The Markdown fixtures (#54, question 13) asked.

## Options

- **(a) A leading BOM is skipped before front matter is detected,** with a `check` warning if the owner wants one. Chosen, as
  recommended.

Other options: Not recorded.

## Decision

(a), as card H3's option (a), accepting every recommendation. A leading UTF-8 byte order mark is skipped before front matter is
detected. The answer is about Markdown, and §5.3 applies it there only; JSON and YAML records are not covered. No warning was
asked for.

## Why

Not recorded. The card's note for all sixteen items: each recommendation keeps vmd strict and its output readable back, and none
contradicts an earlier decision.

## Applied in

Draft v0.5 (#57, `d0d1424`), §5.3. [I1.4](I1.4.md) widened it to JSON and YAML records, with only a BOM at byte 0 counting as
one, in every format.
