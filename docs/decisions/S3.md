## Question

`outline` lists each section's canonical address, title and token estimate; it lists no block anchors, and gives one line for a
JSON or YAML record (#84, its tenth open question). What does `outline` list?

## Options

- **(a) Add block anchors, indented under their section, and list a data record's top-level members.** Chosen, as recommended.
- **(b) Keep #84's interim reading.** No block anchors, and one line for a JSON or YAML record.

## Decision

(a), as part of card S's option (a), accepting every recommendation.

## Why

The card's reason: `outline` is then useful for every format.

Why the other options lost: Not recorded.
