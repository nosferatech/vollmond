## Question

`get --body` on a node that is not a section fails with `address-not-found` (#84, its ninth open question), which reads oddly, since
the address is fine. What does it fail with?

## Options

- **(a) `usage-invalid` with a hint.** Chosen, as recommended.
- **(b) Keep #84's interim reading.** `address-not-found`, though the address resolves.

## Decision

(a), as part of card S's option (a), accepting every recommendation: `--body` on a node that is not a section is `usage-invalid`,
with a hint. `usage-invalid` is the operation code of [O4](O4.md).

## Why

The card's reason: the address is fine and the option does not apply, so the error should say that, which `address-not-found`
does not.
