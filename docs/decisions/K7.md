## Question

Question 7 of the phase I1 design (#59), item 7 of card K. §7.3 says "the item at that decimal index", and RFC 6901 forbids
leading zeros in an exact path's array index. What does `#links/01` match in a semantic path?

## Options

- **(a) Nothing, as in an exact path.** Chosen, as recommended, with cases for both kinds of path.
- **(b) Item 1.**

## Decision

(a), through card K's option (b), which accepted every recommendation but question 3's: leading zeros in an index step, as in
`#links/01`, match nothing, in a semantic path as RFC 6901 requires of an exact one (§7.3), with cases for both kinds of path.

## Why

The design's and the card's reason: as RFC 6901 already requires for exact paths.

Why the other options lost: Not recorded.

Draft v0.7 (#61, `c3032a6`), §7.3.
