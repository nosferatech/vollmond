## Question

YAML anchors, aliases and tags are valid YAML, and some authors share schema definitions with them. vmd's YAML rules
(card H2, [H2.3](H2.3.md) for tags among them, and [J5](J5.md)) refuse them in records. Are they allowed in schema files?

## Options

- **(a) Schema files follow vmd's YAML rules.** Chosen, as recommended. Anchors, aliases and tags are `schema-invalid`; `$defs`
  with `$ref` does the same job.
- **(b) Plain YAML 1.2 for schema files.** A second YAML reading for one kind of file.

## Decision

(a). §9.2 says so.

## Why

The card's reason: "One YAML reader, one set of rules, for every file vmd reads." The design: J5's spirit, and `$defs` with
`$ref` does what anchors do. The card's consequence for (b), not a reason it gives against it: a second YAML reading for one
kind of file.
