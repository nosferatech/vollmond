## Question

When a section has no text, or holds only a data block, is its `$body` absent or `""`? The Markdown fixtures (#54, question 1)
held back cases on it, with inputs such as `# Record`, a blank line and `## Part`, where neither the root nor `Part` has text, a
section holding only a data block, and a file holding only front matter.

## Options

- **(a) `$body` is absent.** Chosen, as recommended. §5.4 already makes an empty Markdown file `{}`, and `{"$title": "Part"}`
  round-trips. §5.8 then lists `$body: ""` among the values the Markdown serializer refuses. A body of only blank lines is
  absent too.
- **(b) `$body` is `""`.**

## Decision

(a), as card H3's option (a), accepting every recommendation. An empty `$body` is absent, never `""`. §5.8 now refuses
`$body: ""`, which Markdown cannot write apart from an absent body.

## Why

The card's reason: as an empty file is already `{}`. The PR's reason: (a) lets `{"$title": "Part"}` round-trip, while Markdown
cannot write `""` apart from an absent body, so (b) would give a value that does not read back. The card's note for all sixteen
items: each recommendation keeps vmd strict and its output readable back, and none contradicts an earlier decision.
