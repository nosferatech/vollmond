## Question

§9.1 allows any string as a collection name. Names are used in `targets` ([U9](U9.md)) and in §7.6's `collection:key` shorthand,
so `/`, `*` or `:` in a name would be ambiguous.

## Options

- **(a) Names match `[A-Za-z][A-Za-z0-9_-]*`.** Chosen, as recommended. Another name is `config-invalid`. §9.1 states the
  pattern.
- **(b) Any string, with escaping.** `targets` and the shorthand need an escaping rule.

## Decision

(a): a collection name matches `[A-Za-z][A-Za-z0-9_-]*`, and a configuration with another name is `config-invalid`.

## Why

The card's reason: "No real name needs more, and it removes the ambiguity at the source." (b) needs an escaping rule in `targets`
and in the shorthand.
