## Question

Draft v0.1's write path, `tx begin` / `op` / `status` / `commit`, costs several turns. The review proposed making "edit with
normal tools, then `vmd check`" first-class, and keeping semantic operations for refactors and remote backends, through one
`apply` call. How do agents write?

## Options

- **(a) Edit with normal tools, then `vmd check`**; semantic operations for refactors and remote backends through one `apply`.
  Chosen, as the review proposed.
- **(b) Draft v0.1's staged transactions**, `tx begin` / `op` / `status` / `commit`, which cost several turns.

## Decision

(a). Standard tools are preferred. Defining a core set of text-editing operations that a non-shell system must support (a "core
of sed") may be useful.

## Why

The review's reason: agents already have strong habits with editing tools and `sed`, and the staged sequence costs several turns.
Why (b) lost beyond that: Not recorded.
