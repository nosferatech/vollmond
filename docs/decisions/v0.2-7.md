## Question

The session asked: is a section's data block exactly one, and only the first block after the heading (a per-section front
matter), or may it stand anywhere in the section?

## Options

- **(a) Exactly one, immediately after the heading.** Chosen: both the canonical and the strict form.
- **(b) Anywhere in the section.** It would have to be enabled explicitly, would not round-trip, and would break source tracking,
  since the body would no longer be continuous.

## Decision

(a). Exactly one, immediately after the heading. This is both the canonical and the strict form. Data blocks elsewhere in a
section are not supported, and probably never will be: they would break round-trips and the continuity of `$body`.

## Why

The owner's reasons against (b): a setting allowing data blocks anywhere would not round-trip, and would affect span and source
tracking, since the body would no longer be continuous. The session agreed and added that it would complicate source tracking.
