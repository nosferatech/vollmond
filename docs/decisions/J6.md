## Question

Item 6 of card J, from the independent review of #58: the owner chose "any node in the store" as the default `targets` of an
`x-vmd-ref` ([I1.11](I1.11.md)), which would exclude a reference to an asset, such as an image, or to a directory. What does an
`x-vmd-ref` without `targets` allow?

## Options

- **(a) Any node in the store, as decided in I1.11.** References to assets and directories are excluded.
- **(b) Any target, assets and directories included.** Chosen, as recommended.

## Decision

(b), through card J's option (a), accepting every recommendation: an `x-vmd-ref` without `targets` allows any target, nodes,
records, assets and directories (§9.3). This widens I1.11, which allowed any node.

## Why

The card's reason: a missing constraint should not add one, and I1.11's "any node" excludes assets and directories. For the whole
card: each recommendation "keeps one rule per thing and matches what the libraries vmd builds on can check".

Draft v0.7 (#61, `c3032a6`), §9.3.
