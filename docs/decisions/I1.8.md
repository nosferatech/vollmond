## Question

Item 8 of card I1, from #57's open questions: what is a `cardinality: many` reference to a record that does not exist, such as
`other.md#items/*` where `other.md` is missing?

## Options

- **(a) `ref-dangling`.** Chosen, as recommended. The record part of a reference is always singular.
- **(b) An empty result, as [G5](G5.md) gives a many-reference that matches nothing.** A typo in a path would be hidden as an
  empty result.

## Decision

Card I1's option (a), accepting every recommendation. A many-reference to a record that does not exist is `ref-dangling`, since
the record part of a reference is always singular. G5's empty result stays for a record that exists with nothing matching (§8.2,
§8.5, Appendix D).

## Why

The card's reason: the record part of a reference is always singular, so a typo in a path is not hidden as an empty result.
