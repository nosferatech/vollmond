## Question

In §7.1's grammar, is an empty anchor name the record's root?

## Options

- **(a) An address with no fragment, or with an empty one, is the root**, and the grammar makes the fragment optional. Chosen.

Other options: Not recorded.

## Decision

(a). An address with no fragment, or with an empty one, is the record's root. The session noted one trap in the text: `#/` is not
the root, since as a JSON Pointer it means the member whose name is the empty string.
