## Question

Is a `json data` block read as JSON or as YAML? `{owner: ana}`, `{"owner": "ana",}` and a `#` comment line are all YAML 1.2 and
none is JSON. The Markdown fixtures (#54, question 10) asked.

## Options

- **(a) JSON,** so each of those is a `syntax-error`. Chosen, as recommended.
- **(b) YAML,** as front matter is.

## Decision

(a), as card H3's option (a), accepting every recommendation. `json data` is parsed as JSON, and `yaml data` as YAML (§5.3).

## Why

The PR's reason: the first word names the format. Why (b) lost: Not recorded. The card's note for all sixteen items: each
recommendation keeps vmd strict and its output readable back, and none contradicts an earlier decision.
