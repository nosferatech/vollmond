## Question

Used as a selector, `shadow.md#notes`, where `notes` is a root field and also a deep `### Notes` heading's anchor, could give
both nodes or neither. The same holds for a lenient `#entry-1` that is one node's derived anchor and another's explicit anchor.
(#53, question 8.)

## Options

- **(a) Every match,** as §5.7 says of lenient selectors. Chosen, as recommended.
- **(b) Neither node.**

## Decision

(a), as card H4's option (a), accepting every recommendation. Selectors over an ambiguous name return every match (§7.4).

## Why

The PR's reason: §5.7 already says so of lenient selectors. Why (b) lost: Not recorded. The card's note for the six items: each
recommendation keeps vmd strict and its output readable back, and none contradicts an earlier decision.

## Applied in

Draft v0.5 (#57, `d0d1424`), §7.4. R5 later fixed the order of a selector's matches as document order.
