## Question

The draft gave no address for a node that no step can name: the member with the empty name, reachable only as `#/`, or a section
with the empty key (§5.5). The address fixtures (#53, question 9) also asked how a canonical address writes characters outside
`step`.

## Options

- **(a) The exact path, where no step can name the node.** Chosen, as recommended. For the characters outside `step`, the PR
  recommended UTF-8 percent-encoding with upper-case hex (RFC 3986).

Other options: Not recorded.

## Decision

(a), as card H4's option (a), accepting every recommendation. A node that no step can name, such as a member with the empty name
or a section with the empty key, has its exact path as its canonical address (§7.5). The first part of question 9, how a
canonical address percent-encodes characters outside `step`, is not answered by H4; I1.2 answered it.

## Why

Not recorded. The card's note for the six items: each recommendation keeps vmd strict and its output readable back, and none
contradicts an earlier decision.

Draft v0.5 (#57, `d0d1424`), §7.5.
