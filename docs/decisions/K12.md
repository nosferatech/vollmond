## Question

Question 12 of the phase I1 design (#59), item 12 of card K: Appendix D has no code for a read the backend cannot complete, such
as one refused by a permission error. What does such a read report?

## Options

- **(a) A new operation code, `storage-failed`.** Chosen, as recommended.
- **(b) `address-not-found` for every failed read.**

## Decision

(a), through card K's option (b), which accepted every recommendation but question 3's: `storage-failed`, a new operation code,
for a read that the backend cannot complete, such as one refused by a permission error, which is not `address-not-found` (§11.2,
Appendix D).

## Why

The design's and the card's reason: a permission error is not a missing record, so (b) would misreport it.

## Applied in

Draft v0.7 (#61, `c3032a6`), §11.2 and Appendix D.
