## Question

YAML allows a raw U+FFFE or U+FFFF inside quotes, while §4.1 makes it an error everywhere. Which rule holds inside quotes?

## Options

- **(a) Keep vmd's stricter rule**, and record it as a departure from YAML, like the byte order mark rule. Chosen, as
  recommended.
- **(b) Follow YAML** and accept them inside quotes.

## Decision

(a), with card N's option (a), accepting every recommendation. Raw U+FFFE and U+FFFF inside YAML quotes stay a `syntax-error`.
This departs from YAML, whose quoted scalars accept any `nb-json` character, as vmd departs for the byte order mark (§5.1); the
rule is in §4.1. The `yaml` package (2.9.1) accepts a raw U+FFFE in double quotes.

## Why

The card's reason for the card as a whole: each rule follows YAML or C2 where they speak, and picks the safe reading where they
don't.

Why the other options lost: Not recorded.
