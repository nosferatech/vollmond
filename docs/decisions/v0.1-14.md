## Question

The review listed prior art worth a look: TinaCMS, Decap CMS and Keystatic, Dolt, lakeFS, git-bug, Fossil, Astro content
collections and Obsidian Dataview. May vmd adopt existing solutions?

## Options

- **(a) Adopt prior art where its license is permissive (MIT or similar)**, weighed against how far it would limit the format.
  Chosen.

Other options: Not recorded.

## Decision

(a). Prior art is adoptable if permissively licensed (MIT or similar), weighed against how far it would limit a format whose
requirements will grow.

## Why

The owner's reason for the weighing: the format and its feature requirements may extend over time, so an existing solution could
limit them.

## Owner's note

> for prior art, if a prior art can be used and has compatible permissive license (MIT?) then we can consider adopting that as
> well. However, I'd expect the format and feature requirements may extend over time, so we would need to weight in whether using
> existing solution would limit those.
