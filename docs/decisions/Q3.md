## Question

A data `$tags` array that repeats an invalid tag, as `["bad tag", "bad tag"]`: one `anchor-invalid` or two? The anchor table
(#82, its sixth open reading) checks a repeated tag once. A repeated tag also gives `duplicate-tag`, and the value keeps the repeat
([I1.5](I1.5.md)).

## Options

- **(a) One per occurrence**, as Appendix D's "once per occurrence" reads literally. Chosen, as recommended.
- **(b) One, as the code reads it**, checking a repeated tag once.

## Decision

(a), as part of card Q's option (a), accepting every recommendation: a repeated invalid tag gives one `anchor-invalid` per
occurrence.

## Why

The card's reason: it is how Appendix D's "once per occurrence" reads literally.

Why the other options lost: Not recorded.
