## Question

§7.5's forms ([H4.1](H4.1.md)) cover nodes only, so two duplicated block anchors in one `$body` would both get the `$body`'s
address. The code falls back to the `$body`'s canonical address and keeps the block's range, a rule not written anywhere (#83, its
third open question; #85, its second). What is the canonical address of a block anchor whose name is not unique?

## Options

- **(a) The `$body`'s canonical address plus the block's range**, as the code does now, and §7.5 says so. Chosen, as recommended.
- **(b) Keep the draft as it is.** §7.5's forms cover nodes only, so both blocks would get the `$body`'s address.

## Decision

(a), as part of card R's option (a), accepting every recommendation.

## Why

The card's reason: a duplicated anchor is already an error, so this only matters while it is being fixed. Card R as a whole
"matches what the code already does and keeps results the same across implementations".

Why the other options lost: Not recorded.
