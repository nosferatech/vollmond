## Question

HTML would decode a character reference in an attribute value, as in `id="a&amp;b"`. Does vmd? The Markdown parser (#79, its fifth
open reading) does not decode them.

## Options

- **(a) Not decoded.** Chosen, as recommended. Anchor names cannot contain `&`, so the value is `anchor-invalid` either way.
- **(b) Decoded, as HTML does.** Every implementation then has to know HTML's entity table.

## Decision

(a), as part of card P's option (a), accepting every recommendation: character references in `<a>` attribute values are not
decoded.

## Why

The card's reason: anchor names cannot contain `&`, so the value is `anchor-invalid` either way, and with (a) nothing has to know
HTML's entity table, which (b) requires.
