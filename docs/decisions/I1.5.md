## Question

Item 5 of card I1, from #57's open questions: [H3.16](H3.16.md) covers a tag repeated in an `<a class>` attribute only. What
about a tag repeated in a data `$tags` array, such as `[a, a]`?

## Options

- **(a) A `duplicate-tag` warning, with the value kept as written.** Chosen, as recommended.
- **(b) Drop the repeat, as H3.16 does for `class` tokens.** In data the array is stored data, so dropping a member would break
  the round trip.

## Decision

Card I1's option (a), accepting every recommendation. A tag repeated in a data `$tags` array gives `duplicate-tag`, and the value
is kept as written. `class` tokens are still dropped (H3.16), since they are parsed rather than stored (§6.2, Appendix D).

## Why

The card's reason: in data the array is stored data, so dropping a member would break the round trip; `<a class>` tokens are
parsed, which is why H3.16 drops them there.

## Applied in

Draft v0.6 (#58, `c3879b7`), §6.2 and Appendix D.
