## Question

The draft does not specify `grep`'s line format. The read commands (#84, its third open question) follow GNU grep:
`path:line:text`, with context lines as `path-line-text`, and `--` between groups only when context is asked for. A path holding
`:12:` makes that ambiguous to parse. Which format does `grep` print?

## Options

- **(a) Keep GNU's format, and add `--json` for exact parsing**, which is already there. Group by path only in `query`. Chosen, as
  recommended.

Other options: Not recorded.

## Decision

(a), as part of card S's option (a), accepting every recommendation.

## Why

The card's reason: agents and people already read GNU grep's format, and `--json` gives exact parsing. Card S as a whole keeps the
output "safe for a terminal, cheap in tokens, and exact for programs".

Why the other options lost: Not recorded.
