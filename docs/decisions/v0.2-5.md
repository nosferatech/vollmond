## Question

A section's text is raw Markdown in the value view. Some users may want to query specific rows or columns of a table in it. Are
tables addressable?

## Options

- **(a) Later, through a read-only views extension.** Chosen. For example, `#/…/$tables/0/rows` would project a GFM table as an
  array of row objects; full-text search already reaches cell contents.

Other options: Not recorded.

## Decision

(a). Tables become addressable later, through a read-only views extension.

## Why

The owner's reason: querying table contents looks like an extension that would affect only reading and searching.
