## Question

"Each node after the first" ([H1.3](H1.3.md)) follows file position in the anchor table (#82, its third open reading). So for the
same record the issue lands on a different node in Markdown, at the root, since its title comes after the front matter, than in
JSON, at `/meta`. Which order decides which duplicate is "after the first"?

## Options

- **(a) Document order means pre-order:** a node before its descendants, and siblings in file order, so all formats agree. Chosen,
  as recommended.
- **(b) File position, as the code reads it.** The issue lands on a different node in each format.

## Decision

(a), as part of card Q's option (a), accepting every recommendation: document order is pre-order. This refines H1.3's counting
rule.

## Why

The card's reason: each section keeps one issue location across all three formats. Under (b) the location depends on the format.
