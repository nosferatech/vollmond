## Question

The review asked: Rust like vampiredb, or Python like the Belfry CLI? The choice affects the YAML round trip and Markdown span
parsing, and whether a Belfry Lambda can reuse the library.

## Options

- **(a) Rust**, like vampiredb.
- **(b) Python**, like the Belfry CLI.
- **(c) Python and/or JavaScript.** Chosen, from the owner's answer.

## Decision

(c). Python and/or JavaScript. Rust has no need to interface with vmd. The customers are agents, humans, CI jobs, and reporting
and management websites and services.

## Why

The owner's reason: nothing in Rust needs to interface with vmd, and for the main customers (agents, humans, CI jobs, reporting and
management websites and services) Python and/or JavaScript would probably be the first choice. Why (b) alone lost: Not recorded.
