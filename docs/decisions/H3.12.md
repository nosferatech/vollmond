## Question

Do level-1 headings inside a block quote, a list item or an HTML block count for the title rule and for `multiple-h1`? The
Markdown fixtures (#54, question 11) asked with `# Record`, then `> # Quoted`, then text.

## Options

- **(a) Only headings outside containers count,** so `# Record` is the title and `multiple-h1` does not fire. Chosen, as
  recommended.
- **(b) Every CommonMark level-1 heading counts,** so the root has no title, `# Record` is a section, and `check` warns.

## Decision

(a), as card H3's option (a), accepting every recommendation. Level-1 headings inside container blocks count neither for the
title rule nor for `multiple-h1`.

## Why

The card's reason: containers are prose. The PR adds that §6.3 step 7 counts only vmd sections. Why (b) lost: Not recorded. The
card's note for all sixteen items: each recommendation keeps vmd strict and its output readable back, and none contradicts an
earlier decision.
