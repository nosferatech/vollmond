## Question

Where does a record carry its metadata? The review of Draft v0.1 listed the carriers in use or proposed: YAML front matter (v0.1's
assumption), vampiredb's header table (`| **Status** | In progress — prose |`, parsed into a value and a note), or a fenced
block.

## Options

- **(a) YAML front matter.** Chosen.
- **(b) vampiredb's header table**, with `keyword — prose` parsed to `{value, note}`.
- **(c) A YAML or JSON block inside the body.** Chosen.

## Decision

Front matter, and YAML or JSON blocks inside the body, are all acceptable.

## Why

Not recorded. The owner answered "those options look good" and named the YAML and JSON blocks; the answer does not mention the
header table.
