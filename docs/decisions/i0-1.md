## Question

The workspace task (I0.1, #39) found that the npm name `vmd` is taken: an unrelated Markdown-preview package installs a `vmd`
command globally. `@vollmond/core` and `@vollmond/cli` are free. vmd's package could still install a command called `vmd`, but
anyone with the other package installed globally would get a clash. What are the package and command names?

## Options

- **(a) Keep `vmd` as the command** and accept the rare clash.
- **(b) Rename the command**, for example `vollmond`, with `vmd` as an optional alias.
- **(c) Name it `vmd`, but document `npx @vollmond/cli` as the safe way to run it.**

## Decision

The npm packages are named `vollmond`: `@vollmond/core` and `@vollmond/cli` (both free, as is the unscoped `vollmond`). The
command is `vmd`, although the unrelated npm package `vmd`, a Markdown previewer unmaintained for eight years, installs a command
of the same name. That is (a), with the packages under the `vollmond` scope.

## Why

The owner's reason: the other `vmd` package has not been maintained in eight years. Why (b) and (c) lost: Not recorded.
