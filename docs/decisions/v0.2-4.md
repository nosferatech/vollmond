## Question

With spans out of the data model ([v0.2-3](v0.2-3.md)), what does an error message say about where the problem is?

## Options

- **(a) `line:col` where a source file exists, plus the semantic path, the exact path, candidates and a hint.** Chosen. A database
  backend without a source file prints the same message without the `file:line:col` prefix.

Other options: Not recorded.

## Decision

(a). Error messages give `line:col` where a source file exists, plus the semantic path, the exact path, candidates and a hint.

## Why

The owner's reason: error messages should be as friendly as possible, so `line:col` where available, and an identity path as
well.

## Owner's note

> re 3: spans. For errors messages, they should be as friendly as possible. So using line:col if available is great, and
> referening a identity path would not hurt either.
