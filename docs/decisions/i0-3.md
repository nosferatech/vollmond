## Question

TypeScript 7, Biome and Vitest's bundler all ship platform-specific binaries. The plan's "no native dependencies" was about the
index cache, so it does not settle whether development tools may be native.

## Options

- **(a) Allow them, provided the runtime dependencies of the shipped packages stay pure JavaScript.** Chosen. Costs: a contributor
  on an unusual platform might find no prebuilt binary, and npm prints a warning about install scripts.
- **(b) Block them.**

## Decision

(a). Native development tools are allowed (TypeScript 7, Biome, Vitest's bundler ship platform binaries), provided the runtime
dependencies of the shipped packages stay pure JavaScript.

## Why

The session's answer to the owner's question whether there is any reason to block them: no, since the packages ship plain
JavaScript and only the build, lint and test tools are platform binaries.
