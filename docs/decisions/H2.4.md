## Question

Item 4 of card H2, from #52 Q6. Which `<<` is a merge key? The inputs are a quoted `"<<": {a: 1}`, which the `yaml` package reads
as a plain member, and `<<: 1`, a merge key with a value that is not a mapping.

## Options

- **(a) A plain `<<` key is always a merge key, whatever its value, so `yaml-merge-key`; a quoted `"<<"` is an ordinary
  member.** Chosen, as recommended.

Other options: Not recorded.

## Decision

(a), with card H2's option (a), accepting every recommendation. A plain `<<` key is always a merge key, whatever its value, and so
`yaml-merge-key`. A quoted `"<<"` is an ordinary member (§4.1).

## Why

The reason in #52 Q6: YAML 1.1's merge applies only to the plain scalar; the card adds that YAML itself settles the quoted case,
and that a plain `<<` is then rejected like any merge key. Card H2's reason for accepting every recommendation: each keeps vmd
strict and its output readable back, and none contradicts an earlier decision.
