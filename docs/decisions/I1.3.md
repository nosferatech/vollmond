## Question

Item 3 of card I1, from #57's open questions (#53, case format): is an input member that a conformance case's operation does not
take an unknown member?

## Options

- **(a) An error: the runner stops with exit code 2, as for any unknown member.** Chosen, as recommended. Strict, so a typo
  cannot silently skip part of a case.

Other options: Not recorded.

## Decision

Card I1's option (a), accepting every recommendation. An input member that the operation does not take is an error in the case
file, and the runner exits with 2 (suite README). Other unknown members still make the case an `error`, so the suite has two
treatments; the log notes that the owner's answer names the exit code, and it is applied as given.

## Why

The card's reason: strictness, "so a typo can't silently skip part of a case".

Why the other options lost: Not recorded.
