## Question

The review of the conformance runner (#65) caught it treating `[1]` as equal to `[1, 2]`, and no suite case checked that. Should
the suite hold every runner to comparing array lengths?

## Options

- **(a) Add a `compare` case.** Chosen, as recommended. Every runner in every language is held to it.

Other options: Not recorded.

## Decision

(a), with card L's option (a), accepting every recommendation. A `compare` case in each direction asserts that `[1]` does not
equal `[1, 2]`, so every runner is held to comparing array lengths.

## Why

The card's reason: no suite case checked array length, and a `compare` case holds every runner in every language to it. For the
card as a whole: each default is the safe one, and the reviewers checked them.

Why the other options lost: Not recorded.
