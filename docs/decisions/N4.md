## Question

What is a YAML file holding `---` with nothing after it? YAML reads an empty document as null (YAML 1.2.2, section 7.2), and
PyYAML gives `None`. An empty file is the empty record, by [C8](C8.md).

## Options

- **(a) `root-not-object`, following YAML.** Chosen, as recommended.
- **(b) The empty record**, as an empty file is.

## Decision

(a), with card N's option (a), accepting every recommendation. A YAML file holding only `---` is a document whose root is null
(YAML 1.2.2, section 7.2), so it is `root-not-object`, while an empty file stays the empty record (C8) (§5.4), with a case.

## Why

The card's reason: it follows YAML, which reads the document as null, as PyYAML does. For the card as a whole: each rule follows
YAML or C2 where they speak, and picks the safe reading where they don't.

Why the other options lost: Not recorded.
