## Question

An undefined tag handle, such as `!e!x`, is an error either way. Under [H2.3](H2.3.md) every explicit tag is `yaml-tag`. Which
code does it get?

## Options

- **(a) `syntax-error`**, which is what PyYAML and ruamel report. Chosen, as recommended.
- **(b) Only `yaml-tag`**, as for every other explicit tag.

## Decision

(a), with card N's option (a), accepting every recommendation. An undeclared YAML tag handle, such as `!e!x`, is a `syntax-error`,
not `yaml-tag` (§4.1, YAML 1.2.2, section 6.8.2.1). This narrows H2.3's code for that case; every other explicit tag stays
`yaml-tag`.

## Why

The card's reason: `syntax-error` is what PyYAML and ruamel report. For the card as a whole: each rule follows YAML or C2 where
they speak, and picks the safe reading where they don't.

Why the other options lost: Not recorded.
