## Question

How do agents reach vmd: a command line or an MCP server?

## Options

- **(a) A CLI plus a short skill file.** Chosen, as the review recommended. It costs nothing until it is used.
- **(b) An MCP server.** Its tool schemas are paid for in every session.

## Decision

CLI first. MCP only where its benefit outweighs its cost.

## Why

The review's reason: a CLI plus a short skill file costs nothing until used, while MCP tool schemas are paid for in every session
(Belfry's README already noted it).

## Owner's note

> cli vs mcp: cli sound good. The mcp is optional, and only if it provides favorable benefit to cost.
