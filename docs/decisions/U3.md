## Question

§7.4 says that a path through a level declared `multimap` cannot be singular, but §8.5 gives no reference status for it. The rule
covers every form of reference: Markdown links, `$ref` objects and typed strings. What is the status of such a reference?

## Options

- **(a) Status `ambiguous`, issue `ref-ambiguous`.** Chosen, as recommended. The message says it cannot be proved singular; §8.5
  and Appendix D name the case.
- **(b) A new code `ref-not-singular`, status `ambiguous`.** As stated.
- **(c) Evaluate it, and accept it when one node matches.** Contradicts §7.4.

## Decision

(a): a reference through a `multimap` level has the status `ambiguous` and the issue `ref-ambiguous`, whose message says it
cannot be proved singular, for every form of reference.

## Why

The card's reason: "Keeps one code per status, and the declaration already says several nodes may match." (b) gives the one
status a second code; (c) contradicts §7.4.
