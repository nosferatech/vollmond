## Question

Blocks cannot carry `$tags`. The Markdown parser (#79, its sixth open reading) made an anchor element with a `class` at the start
of a block `anchor-element-invalid`, "a block cannot carry tags", a structural error. Should it make the record unreadable?

## Options

- **(a) A validation error**, so the record stays readable, as for other unsupported HTML ([C15](C15.md)). Chosen, as recommended.
- **(b) Keep the draft as it is.** A structural error, so the record cannot be read.

## Decision

(a), as part of card P's option (a), accepting every recommendation: a `class` on a block anchor is a validation error, and the
record stays readable.

## Why

The card's reason: so the record stays readable, as for other unsupported HTML in C15; card P as a whole "picks the reading that
loses no data silently". The card's account of (b): "Today it's a structural error."
