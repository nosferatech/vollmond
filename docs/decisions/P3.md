## Question

A file that starts with `<!-- markdownlint-disable -->` and then `# Title` loses its title: the comment is the first block, so the
level-1 heading becomes a section. That is common in real files. Does such a comment count as the first block for the title rule?
The question came from the independent review of the Markdown parser (#79).

## Options

- **(a) HTML blocks that hold only comments do not count as the first block for the title rule.** Chosen, as recommended.
- **(b) Keep the draft as it is.** The comment is the first block, and the heading becomes a section, so the record has no title.

## Decision

(a), as part of card P's option (a), accepting every recommendation: HTML blocks that hold only comments do not count as the first
block for the title rule. The owner's note on the card raised a related question, comments in JSON blocks and files, which this
decision does not answer.

## Why

The card's reason: "That's common in real files", and card P "picks the reading that loses no data silently". (b) drops the
title of such files.
