## Question

§5.3 said "CommonMark with the GitHub extensions" without versions, while §6.3 pins the Unicode version through the suite, and
the fixtures cite CommonMark 0.31.2, as §8.1 already did. Which CommonMark and GFM does vmd read? (#54, question 14.)

## Options

- **(a) §5.3 pins CommonMark 0.31.2 and GFM 0.29,** and the suite pins them as it pins the Unicode version. Chosen, as
  recommended.

Other options: Not recorded.

## Decision

(a), as card H3's option (a), accepting every recommendation. §5.3 pins CommonMark 0.31.2 and GFM 0.29, the GFM specification's
latest version (0.29-gfm, 2019-04-06, checked on 2026-10-10).

## Why

The card's reason: §8.1 already cites CommonMark 0.31.2. The card's note for all sixteen items: each recommendation keeps vmd
strict and its output readable back, and none contradicts an earlier decision.
